## What's new

First public **beta** of the Aefos AI **Lazarus / FPC** edition — the same agentic in-IDE AI assistant, now on Lazarus. The Lazarus edition versions independently of the Delphi edition (its own `0.x` beta line; `1.0.0` is reserved for its GA, as with the Delphi edition's history).

**Docked Chat** — a side panel integrated into the IDE, driven by *your own* AI CLI (Codex / Claude / Gemini / Copilot, or Ollama for local models). Provider, model and executor path are set on the Welcome page, no project open.

**Live Form Designer** — the agent opens the Form Designer and adds components, sets properties and creates event handlers, appearing in the Object Inspector live. This is the Object Pascal differentiator: Design mode *and* Code mode, which text-only IDEs lack — guarded by the RULE #1 intent guard (a Design command in Code view is rejected, and vice-versa).

**Native docked Terminal** (own-canvas render, no WebView): correct Unicode + box/half-block drawing, mouse **selection + copy/paste** (with bracketed paste), **scrollback + scrollbar**, and **find (Ctrl+F)**.

**Action Center** — a category-grouped catalogue of saved actions you run straight into the terminal. One brain with the Delphi edition: the same `actions.json`, so actions cross both editions.

**Terminal AI composer** (Ctrl+I) — a bar to turn a request into a command in the pane's running CLI, with a floating `/command` picker.

**In-process MCP server** — the agent drives the IDE over a standard protocol (open unit, form designer, edit, build, git), with view (Design/Code) intent guards and the change-review gutter.
